# Working on the paper from a cloud session

State on 2026-10-12: `main` contains the frozen field results (tag `freeze/field-2026-10-12`) and the manuscript,
captions and Supplementary Information rewritten on them (PR #51). Everything a cloud session needs is in this
repository, in the private repository `stloendays/Catalyst-Essay-sources` and in one Google Drive folder.

```bash
gh release download freeze-field-2026-10-12 -R stloendays/Catalyst-Essay-sources -D sources
for z in sources/*.zip; do unzip -q -o "$z" -d .; done          # paper and data paths land where .gitignore expects them
export NH3_HARNESS=$PWD/Catalyst_Economic_Leverage_Automation_Harness_v0.1   # scripts that need the full harness
```

Without the private archives, the NH₃ harness can be rebuilt from `provenance/` with
`analysis/nh3_actual_ru_params_2026_10_07/build_harness_root.py` (as the verification workflows do); the response-surface
cache is then recomputed.

## Rules for changing the text

- Every number in the text comes from a committed output of the frozen version. After any edit run
  `python tools/audit_live_manuscript_truth.py` (89 checks; the `manuscript-number-audit` workflow runs it on every push).
  When a result changes, change the analysis output first, then the text, then the audit expectation if needed.
- Field results use printed values only; plot readings and all-entry results are sensitivities.
- Methanol: report the disagreements as another catalyst and as the same catalyst at another temperature, each with its
  denominator and the count with a cost gap above 5 %; report the result without Bansode 2013 alongside.
- Errata are counted by root cause, with rules and cells alongside.
- Supplementary Tables and Extended Data captions are generated; change their generators, not the Markdown.
- Extended Data figures and references must be cited in numerical order; the reference list is renumbered by order of
  first citation (main text, then captions).
- Gold-standard validation: **the author confirmed completion of manual review of the 100 sampled methanol values on 2026-10-12**. The reviewed source-evidence workbook, machine-readable CSV, historical AI audits and explicit author-attestation provenance are under `analysis/verify_2026_10_08/gold_standard_human_review_2026_10_12/`. The original manual cells are left unmodified; full-dataset accuracy is not inferred.
