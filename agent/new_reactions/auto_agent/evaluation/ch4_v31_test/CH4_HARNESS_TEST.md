## 对照留出 TEA（STORE&GO D5.9）

| 量 | 模型 | 留出值 | 是否达标 |
|---|---:|---:|---|
| H2 单耗 t/t CH4 | 0.508 | 0.505 | 是 |
| CO2 单耗 t/t CH4 | 2.821 | 2.785 | 是 |
| 外购能耗 GJ/t | 21.4 | 3.84 | 否 |
| 单位投资 USD/(t/年) | 488 | 621 | 是 |

判定：不通过（3/4 达标，能耗超出两倍容差）。投资第一次落在容差内。

能耗偏高的原因：
- 参考工厂直接用了一条实验室记录的工况（400 °C、常压）；
- 常压下 SNG 提纯耗能 9.3 GJ/t，产品压缩到 30 bar 又耗 3.0 GJ/t；
- 放热反应器还配了 7.3 GJ/t 的外购电加热。

最后一项暴露了门控漏洞：外购预热检查只统计 furnace 类型的单元，这个加热器被标成了 heat_exchanger。

## 据此做的改动（V3.2，来自开发集）

外购预热改为统计加热炉，以及所有没有标明用于冷却的换热器和其他单元。重新检查这次的模型，门控现在会拦下它（exothermic_preheat）。
