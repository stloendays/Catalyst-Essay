# GIST working-document template

## Editing an existing GIST

Use the old document as a topology template:

- preserve chapter sequence unless the science now requires a move;
- preserve useful figures and replace only stale ones;
- preserve the overall density and tone;
- insert new causal tests beside the claim they resolve;
- update headline numbers in every place they appear;
- add new references where the new claim enters the story.

Do not create a new visual language simply because the version number changed.

## Default section pattern

### [Section title: a scientific question or result]

One short paragraph stating the question and why it matters.

[Figure]

**Figure X | [declarative scientific caption].**

One short paragraph:
- what changes in the figure;
- the decisive number(s);
- the scientific interpretation.

Citations belong in the prose when literature supports the model, comparison or mechanism.

## Four-sentence story test

Before export, the entire GIST should be compressible to:

1. What scientific ranking/assumption is being tested?
2. What changes after propagation to the decision objective?
3. What physical/process mechanism controls whether the ranking changes or survives?
4. What design or compute-allocation consequence follows?

If this summary cannot be written cleanly, the GIST is not yet structurally resolved.

## Figure-density heuristic

For a mature research project with an established Figure 1–10 map, retain roughly that evidence density. A GIST may combine closely related panels, but should not replace the evidence chain with one infographic unless the user explicitly asks for a one-page poster.

## Reference pattern

Use references in scientific-function order rather than as an undifferentiated pile:

- field paradigm / descriptor screening;
- primary reaction/model source;
- process/TEA source;
- closest integrated-design prior art;
- transfer-case source;
- control/calibration source;
- Agent/autonomous-science context if needed.

A concise working GIST usually needs enough references to let an advisor trace the key inputs and novelty claims, not every citation intended for the final manuscript.

## Naming examples

Good:

- `GIST-v2.docx`
- `GIST-v3.docx`
- `Catalyst-GIST-v4.docx`

Do not use:

- `GIST-v2_中文版.docx`
- `GIST-v2_修订版.docx`
- `GIST-final.docx`
- `GIST-new.docx`
- `GIST-v3_增补版_2026-09-20.docx`
