# Post-outcome extension protocol | pressure-corrected source VLE transferred to five plant inlet cases

**Declared AFTER the BASF 28-point blocked-CV findings (positive) and AFTER seeing previous source-tabulated-only counterfactual (1/5), but BEFORE implementing/running this extension.** It is exploratory and **not** a preblinded new plant experiment. Do not rebrand this as independent prospective field validation.

## Fixed source model and external evaluation

- No industrial plant observation is used to select or fit coefficients; fit **M1 (PRIMARY, one nonnegative effective pressure coefficient)** and **M2 (SECONDARY, pressure coefficient + log-intercept)** from ALL 28 BASF/Ullmann N2:H2=1:3 vapor rows using exactly the already committed definitions and optimizer in 'vle_cv.py'. Fit them on source data only, not on five external plant NH3 inlet values.
- Re-evaluate exactly five preregistered NH3-FINAL-1.2 *failed* plant inlet metrics: A01 TOP140, A04 TOP220, A07 UHDE188, A14 KELLOGG150, A16 BRAUN150. Preserve original published inlet values, original source process cases, same operation T/P/Tsep/capacity, reaction law, closed-loop mass balance, catalyst and model physics/cost objective.
- Source code for model state unchanged: use pinned 'analysis/nh3_industrial_validation_2026_10_14/bootstrap_replay.py' and the original NH3-FINAL-1.2 adapter 'nh3_model.py' after 'prepare()', then 'build_frozen()'/'reproduce_anchors()'. The temporary bounded 'h.psat_nh3_bar' method override is scoped to ONE evaluation and is undone in finally. This is precisely the original one-factor thermodynamics intervention used in 'diagnose_separator_vle.py' with a different **SOURCE-FITTED** vapor fraction; no changes to permanent canonical library.
- Controls on all five cases: M0 original model prediction (must agree with unchanged 'results_metrics.csv' within 2e-5 mole-percent), external BASF table bilinear interpolation (no fit, only at table-covered source T/P), M1 source-fitted correction, M2 source-fitted correction. Record source vapor NH3 percentage, post-recycle reactor inlet percentage, process cost and whether the state solver returns a valid solution; retain infeasibility if any.
- Apply original metric-specific band 'rel:0.20' without changes. For each external industrial observation compute relative error of predicted reactor inlet vs published source. Report number within original ±20% and mean abs percentage error for each strategy across all five. Missing, out-of-domain or infeasible predictions are counted as failures, never dropped from denominator.
- M1 is the predefined candidate; M2 is supplemental. Outcome comparison uses five printed external industrial inlets, but those have been previously observed by the team, so no prospective blinding claim. A gain above earlier 1/5 tabulated-only observation is an independent **source-to-source transfer** check, but still does not validate chemical mixture VLE, whole-plant compressor/refrigeration, kinetic/heat-transfer model, catalyst economic ranking or other original 64 registered criteria.
- Source representation is 1:3 N2:H2, may differ from industrial N2/H2/Ar/CH4/NH3 mix, recycle topology and pressure. Do not claim thermodynamic fundamental K-values, composition independence, source-fit parameter universality or final EOS.
- Preserve 32/64 total and V01 (separator reference) 0/1 original verdict in the main paper. A conditional M1 intervention is NOT a registered upgrade to NH3-FINAL-1.2.
- A success or failure is reported equally with all five rows and error bars. Do not modify the source fit after viewing the five results.
